# Catálogo para ventas por WhatsApp

Una plataforma orientada a pequeños comercios y emprendedores que venden sus productos mediante grupos de WhatsApp.

El objetivo es centralizar el catálogo, el stock y los pedidos en un único lugar, simplificando el proceso de venta y mejorando la experiencia del cliente.

---

## Características

### Clientes

- Acceso sin registro.
- Visualización de productos.
- Búsqueda de artículos.
- Filtrado por categorías.
- Carrito de compras.
- Generación automática de pedidos.
- Envío del pedido mediante WhatsApp.

### Administradores

- Gestión de productos.
- Gestión del stock.
- Gestión de pedidos.
- Control de ventas.
- Panel de administración.
